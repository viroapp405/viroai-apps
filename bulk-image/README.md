# استودیو تولید انبوه تصویر و استخراج استایل · صبا

ساخته‌ی سید صبا میری · [viroai.ir](https://viroai.ir) · اینستاگرام viromedia404 · [تلگرام](https://t.me/viroaihub) · 💚 [حمایت مالی](https://smiri.netlify.app/)

تولید انبوه تصویر با Gemini (هر خط یک پرامپت)، استخراج سبک هنری از تصاویر و مخزن سبک‌ها، گالری با دانلود زیپ.

## اجرا
- **Canvas (رایگان، بدون کلید):** فایل `canvas-loader.html` را در یک چت جدید Canvas اجرا کنید. لودر نسخه‌ی تازه را از گیت‌هاب (`viroapp405/viroai-apps/bulk-image/index.html`) می‌گیرد؛ آپدیت‌ها فقط با push روی گیت‌هاب انجام می‌شوند و لینک اشتراک Canvas ثابت می‌ماند.
- **اکستنشن کروم:** پوشه‌ی `extension/` (میان‌بر Alt+B). ذخیره‌ی دائمی داده‌ها در اکستنشن (storage bridge، شناسه‌ی `saba-bulk-image`). آدرس `APP_URL` بعد از دریافت لینک اشتراک Canvas جایگزین می‌شود.

## مدل‌ها
- تصویر: `gemini-3.1-flash-image` و در صورت محدودیت، خودکار `gemini-2.5-flash-image-preview` به مدت ۱۰ دقیقه.
- متن (استخراج سبک): `gemini-2.5-flash`؛ با کلید شخصی اختیاری: 3.5-flash-lite / 3.5-flash / 3.8-flash.

## فایل‌ها
- `app/bulk-image-original-gemini.html` — سورس اصلی جمینی (دست‌نخورده)
- `build/build_v2.py` + `build/lib.js` + `build/methods.js` — ساخت نسخه‌ی ۲ از سورس اصلی
- `build/test.js`، `build/test-loader.js` — تست jsdom
- `dist/bulk-image/index.html`، `dist/bulk-image/canvas-loader.html` — خروجی منتشرشده
- `extension/` — اکستنشن MV3
