# کوییزساز استوری صبا

کارت کوییز استوری ۱۰۸۰×۱۹۲۰ برای اینستاگرام، واتس‌اپ و بله، با Gemini.

- ورودی: موضوع، متن یا کپشن ریلز، پلتفرم، نوع کارت (چهارگزینه‌ای، درست/غلط، حدس عدد، نظرسنجی)، تعداد ۱ تا ۵ کارت، مخاطب، لحن
- خروجی: کارت سؤال و کارت جواب (جواب + یک خط توضیح + خط دعوت)، PNG هر کارت، zip همه به‌همراه متن استیکر
- گزینه‌های شماره‌دار روی کارت چاپ می‌شوند تا مخاطب با ریپلای جواب بدهد. برای اینستاگرام هم می‌شود جای خالی برای استیکر Quiz گذاشت (نوشته‌ی «اینجا استیکر» فقط در پیش‌نمایش دیده می‌شود)
- زمینه: تصویری که جمینی از روی موضوع هر سؤال می‌سازد، یا زمینه‌ی آماده‌ی استایل، یا عکس خودت
- ۸ استایل، پروفایل برند (آیدی، لوگو، رنگ، خط دعوت) و چند پروفایل برای چند پیج
- بازبینی خودکار املا و قطعی بودن جواب؛ ویرایش دستی متن روی کارت
- ذخیره در IndexedDB، پشتیبان zip و پل اکستنشن
